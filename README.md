OverTheWire Bandit – Levels 0–15

📌 About

This repository contains my solutions and learning notes from the **OverTheWire Bandit** wargame, covering **Level 0 to Level 15**.

Bandit is designed to teach the basics of Linux commands, file handling, permissions, SSH, networking, and other fundamental cybersecurity concepts through hands-on challenges.

🎯 What I Learned

Through these levels, I practiced:

* Linux command-line navigation
* SSH and remote connections
* File and directory manipulation
* Hidden files
* File permissions
* Searching and filtering files
* Text processing
* Encoding and decoding
* Compression and archives
* Networking basics
* Working with ports and services
* Basic cybersecurity problem-solving
